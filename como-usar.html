Início / Como Usar

Instalação, Execução & Integração

Suba seu próprio nó do Acessília em poucos minutos. Suporte nativo a Docker (GHCR), ambiente virtual com Poetry, consumo via API REST FastAPI e conector MCP Server.

Passo a Passo

Escolha seu Método de Implantação

Ambiente pronto para desenvolvimento local ou servidores de produção de instituições de ensino.

Execução com Docker

Utilize as imagens oficiais publicadas no GitHub Container Registry (ghcr.io):

Bash / Terminal 
# Baixar a imagem completa com Docling, RapidOCR e PyTorch CPU
docker pull ghcr.io/a11ydevs/acessilia:main

# Executar os serviços (API na porta 8000 e painel Web na 8001)
docker run --rm \
  --env-file .env \
  -p 8000:8000 \
  -p 8001:8001 \
  -v "$PWD/var:/app/var" \
  ghcr.io/a11ydevs/acessilia:main

Dica de Desempenho: Para servidores com menos de 8 GB de memória RAM, utilize a versão leve ghcr.io/a11ydevs/acessilia:main-slim.

Instalação com Poetry

Clone o repositório oficial e configure o ambiente com o gerenciador de pacotes Poetry:

Bash / Terminal 
# 1. Clonar o repositório
git clone https://github.com/A11yDevs/acessilia.git
cd acessilia

# 2. Instalar dependências em ambiente virtual isolado
poetry install

# 3. Configurar variáveis de ambiente
cp .env.example .env

# 4. Iniciar todos os serviços integrados (API + Web + Telegram)
poetry run python -m frontend.run

Consumindo a API REST

Envie um arquivo para processamento assíncrono via cURL ou qualquer biblioteca HTTP:

cURL / HTTP 
# 1. Enviar documento PDF para a fila assíncrona
curl -X POST "http://localhost:8000/api/v1/jobs" \
  -F "file=@apostila_calculo.pdf" \
  -F "export_formats=pdf_ua,mp3,html"

# Resposta JSON: {"task_id": "job_94a7e2b1", "status": "queued"}

# 2. Consultar status do processamento
curl -X GET "http://localhost:8000/api/v1/jobs/job_94a7e2b1"

# 3. Baixar versão PDF/UA acessível gerada
curl -O "http://localhost:8000/api/v1/download/{download_token}/pdf_ua"

Integração via Servidor MCP

Conecte o Acessília ao seu assistente de inteligência artificial via Model Context Protocol:

JSON (mcp.json) 
{
  "mcpServers": {
    "acessilia": {
      "command": "python",
      "args": ["-m", "acessilia_toolbox.server"],
      "env": {
        "ACESSILIA_API_URL": "http://localhost:8000"
      }
    }
  }
}

Ferramentas Disponibilizadas: describe_academic_chart, extract_mathml_equations e audit_pdf_ua_compliance.
