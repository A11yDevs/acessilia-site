Início / Ecossistema

O Ecossistema Acessília

Uma suíte modular de ferramentas de código aberto sob a organização A11yDevs, englobando o núcleo de IA, o gestor acadêmico, o conector MCP para agentes e iniciativas satélites de hardware e matemática móvel.

Arquitetura Integrada

Os Quatro Repositórios Centrais

Projetados para desacoplamento e máxima reutilização em ambientes universitários e corporativos.

🧠 Núcleo de IA & Pipeline

Acessília Core

A11yDevs/acessilia ↗

A plataforma principal orientada a agentes para extração estrutural, enriquecimento semântico e transformação documental. Executa a orquestração do pipeline com Docling, RapidOCR, LLMs locais (Ollama) ou em nuvem (OpenRouter) e geradores nativos de PDF/UA, HTML semântico e áudio sintetizado.

  • API REST Assíncrona: Fila de processamento assíncrono em FastAPI com tokens efêmeros de download.
  • Exportadores Nativos: PDF/UA (ISO 14289), áudio sintetizado MP3 com ritmo e capítulos, HTML semântico, DOCX e TXT.
  • Múltiplos Clientes: Painel web acessível, bot interativo do Telegram e interface CLI.
  • Distribuição Docker: Imagens oficiais Linux amd64 no GHCR (variante completa e slim).
Python 3.11 FastAPI Docling RapidOCR Ollama PDF/UA

🎓 Gestão Acadêmica

Acessília UFG (Gestor)

A11yDevs/acessilia-ufg ↗

Camada de aplicação e portal institucional voltado para o fluxo acadêmico universitário. Permite a triagem, solicitação, acompanhamento e entrega de materiais acessíveis para estudantes com deficiência visual matriculados em cursos de graduação e pós-graduação.

  • Fluxo de Demandas: Triagem de apostilas, livros e artigos por disciplina e semestre.
  • Interface Adaptada: Painel com foco total em usabilidade para técnicos transcritores.
  • Integração com o Core: Disparo automático de requisições de conversão para a API central.
Web App Fluxo Acadêmico Gestão de Demandas Ensino Superior

🔌 Integração MCP Server

Acessília Toolbox

A11yDevs/acessilia-toolbox ↗

Conjunto de ferramentas e servidor baseado no Model Context Protocol (MCP). Permite que assistentes inteligentes de IA (como Claude, Antigravity e agentes autônomos) acessem nativamente as funções do Acessília para audiodescrever gráficos, estruturar tabelas e validar conformidade PDF/UA.

  • MCP Tools: Ferramentas expostas via JSON-RPC para pipelines de agentes externos.
  • Auditoria Semântica: Diagnóstico automatizado de contraste, tags e hierarquia de leitura.
  • Extensibilidade: Plug-in leve e interoperável com qualquer cliente MCP compatível.
MCP Protocol AI Agents JSON-RPC Tool Calling

📚 Dados de Avaliação

Acessília Dataset

A11yDevs/acessilia-dataset ↗

Repositório aberto contendo os artefatos de dados, gabaritos estruturais (ground truth) e amostras científicas utilizadas na avaliação do benchmark Dr.DocBench. Inclui documentos reais de física, computação, cálculo e direito com desafios de layout complexo.

  • Amostras Ricas: Fórmulas matemáticas densas, matrizes, circuitos e gráficos multivariados.
  • Ground Truth: Versões anotadas à mão em HTML semântico, MathML e áudio de referência.
  • Suíte de Regressão: Testes contínuos em CI/CD para assegurar não degradação de qualidade.

Projetos Satélites da Comunidade A11yDevs

Expandindo a tecnologia assistiva para além do computador: dispositivos vestíveis, terminais móveis e padrões de publicação.

Acessília Glasses

Hardware Assistivo Vestível

Protótipo de óculos vestíveis inteligentes de baixo custo baseados em Raspberry Pi e microcâmera. Realiza captura de quadros de aula, apostilas impressas e placas de sinalização no campus, enviando para o núcleo de inferência da UFG para sintetizar audiodescrição instantânea no fone de condução óssea do estudante.

Hardware Aberto Raspberry Pi Visão em Tempo Real Condução Óssea

Acessília Math Android

Ambiente Portátil / Termux

Distribuição móvel otimizada para execução local em smartphones Android via Termux. Permite que estudantes de ciências exatas leiam, naveguem e manipulem equações matemáticas densas em MathML, LaTeX e Braille Nemeth diretamente no bolso, inclusive em ambientes sem conectividade com a internet.

Normas Acessília

Especificação Semântica

Manual de diretrizes, esquemas JSON e guias de boas práticas para produção de material didático acessível no ensino superior. Define vocabulários padronizados para audiodescrição de tabelas, circuitos elétricos, diagramas UML e fluxogramas, garantindo consistência em toda a produção editorial acadêmica.
